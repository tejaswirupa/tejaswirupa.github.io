# Tejaswi Neelapu — Editorial Portfolio (V1)

A lightweight, responsive portfolio built with plain HTML, CSS and JavaScript.
No npm, dependencies, or build step required.

## Publish on GitHub Pages

1. Create a **public** GitHub repository named `YOUR_USERNAME.github.io` (replace `YOUR_USERNAME` with your actual GitHub username). Or use any repository name if you prefer the URL `YOUR_USERNAME.github.io/REPOSITORY_NAME/`.
2. Upload **all files and the assets folder** from this package to the **root** of the repository, maintaining the folder structure. You can use **Add file → Upload files** on GitHub.
3. Commit the files to your default branch (`main`).
4. Go to **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select `main`, choose `/(root)`, and **Save**.
5. Open `https://YOUR_USERNAME.github.io/` for a username repository, or `https://YOUR_USERNAME.github.io/REPOSITORY_NAME/` for other repositories. Deployment may take a few minutes.

## Preview locally

Open `index.html` in your browser, or use a simple local server: `python3 -m http.server 8000` then visit `http://localhost:8000`.

## Edit it

- Text and section structure: `index.html`
- Colors, fonts, sizes, photo cropping: `styles.css`
- Mobile navigation: `script.js`
- Main image: `assets/tejaswi-portrait.jpeg`
